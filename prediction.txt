Task 5
1. Initial State:
   - exp1 (CNN Model) will display Epochs: 10/50.
   - exp2 (RNN Model) will display Epochs: 5/30.

2. Independent State & Overload Execution:
   - exp1.runEpochs(10) will call runEpochs(int) and increase exp1.completedEpochs from 10 to 20.
   - exp2.runEpochs(5, 2) will call the overloaded runEpochs(int, int) and increase exp2.completedEpochs by (5 + 2) = 7, raising it from 5 to 12.
   - exp1 and exp2 operate independently, so modifying exp1 will not affect exp2.

3. Remaining Epochs Calculation:
   - exp1.remainingEpochs() will return 30 (50 - 20).
   - exp2.remainingEpochs() will return 18 (30 - 12).

4. Helper Method Pass-By-Value Mutation:
   - Calling modifyExperiment(exp1) will pass a copy of the object reference into the parameter exp.
   - Calling exp.runEpochs(5) inside the helper method will mutate the shared object, increasing exp1.completedEpochs from 20 to 25.
